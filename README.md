# Threat Intelligence Service

REST API сервис для обмена информацией о киберугрозах на основе спецификации OpenAPI 3.0. Позволяет агрегировать и получать данные о вредоносных файлах по их MD5-хешам.

**Проект находится в стадии активной разработки (Work in Progress).** 

## Что планируется сделать
* Написать/дополнить спецификацию OpenAPI (`api/openapi.yaml`).
* Сгенерировать серверный код и модели данных по спеке.
* Реализовать расширенную модель угрозы (добавить поля `severity`, `threat_type`, `detected_at` и валидацию).
* Подключить базу данных [PostgreSQL] для персистентного хранения.
* Покрыть код unit- и интеграционными тестами.
* Упаковать сервис в Docker / Docker Compose для быстрого запуска.

## Стек технологий (целевой)
* **Язык:** [Go]
* **Архитектура:** API-First (генерация кода из OpenAPI)
* **БД:** [PostgreSQL]

## Как развернуть (в будущем)
